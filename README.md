Student Learning Management System (LMS)
A full-stack project built with the MERN stack (MongoDB, Express, React, Node.js). This application is designed to manage student registration and academic data efficiently.
🌟 Key Features
Student Registration: Secure user sign-up and login.
Database Management: Student records stored in MongoDB.
Student Dashboard: Clean and responsive user interface.
REST APIs: Backend routes for managing data.
🛠️ Built With
Frontend: React.js, HTML, CSS
Backend: Node.js, Express.js
Database: MongoDB Community Server (Local)
